# Jarvis Voice Assistant

A Python voice assistant that recognizes spoken commands and responds aloud.

## Features
- Voice recognition
- Text-to-speech responses
- Open websites such as YouTube, GitHub, and LinkedIn
- Search YouTube for music and videos
- Answer basic factual questions
- Tell the current time and date

## Technologies
- Python
- SpeechRecognition
- pyttsx3
- PyAudio

## Run
pip install -r requirements.txt
python main.py
